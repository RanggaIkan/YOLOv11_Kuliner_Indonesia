Jawaban Rubrik: “Ada GUI, Dijelaskan Pakai Bahasa Pemrograman Apa?”

Full-Stack AI CV

Aplikasi GUI NusantaraVision YOLOv11 dibangun menggunakan empat lapisan teknologi utama agar berjalan mulus di browser, server lokal Windows, maupun cloud deployment:

Frontend Web GUI

HTML5 Canvas 2D + CSS3 + Vanilla JS (ES6+)

  • HTML5 Canvas & Video API: Rendering foto makanan resolusi tinggi, frame sequence video, serta manipulasi piksel langsung (ImageData) untuk HE, CLAHE, Contrast Stretching, dan Gamma LUT.
  • Vanilla JavaScript (ES6+): Manajemen state interaktif, drag/resize kotak Object Region #1, visualisasi trail ByteTrack, kalkulator histogram real-time, dan ekspor laporan CSV/Excel.
  • CSS3 Editorial Light Studio: Tata letak responsif berbasis CSS Grid & Flexbox tanpa dependensi eksternal sehingga aman dibuka lewat http:// maupun file://.
AI & Computer Vision

Python 3 + FastAPI + Ultralytics YOLOv11 + OpenCV

  • Ultralytics YOLOv11 (yolo11n.pt): Deteksi 12 kelas kuliner Indonesia, Object Counting, serta pelacakan multi-objek ByteTrack pada citra dan video.
  • OpenCV (cv2) & NumPy: Pemrosesan citra sisi server (YCrCb HE, LAB CLAHE, Percentile CS) dan cv2.pointPolygonTest untuk validasi centroid di dalam Polygon ROI #1.
  • FastAPI & OpenPyXL: REST API endpoint (/api/detect/image, /api/detect/video, /api/export/excel) dan generator workbook .xlsx terformat.
Serverless & Local Runtime

Node.js v24 (server.js & Vercel API)

  • Zero-Dependency HTTP Server: server.js melayani aset statis dan endpoint REST lengkap secara lokal di Windows tanpa keharusan instalasi Python lokal.
  • Vercel Serverless Bridge: api/index.js membungkus handler Node.js untuk endpoint /api/classes, /api/detect/image, /api/detect/video/sample, dan /api/export/excel.
  • Sinkronisasi Katalog Real: Mengonsumsi samples/sample_catalog.json beserta bounding box ground truth dan frame sequence video nyata.
Database & Training

PostgreSQL (Supabase) + Google Colab (.ipynb)

  • PostgreSQL / Supabase REST API: Penyimpanan relasional tabel culinary_classes, detection_sessions, dan enhancement_comparisons dengan Row Level Security (RLS) plus fallback localStorage.
  • Google Colab Notebook (.ipynb): Pelatihan model YOLOv11 di GPU T4 menggunakan 600 citra dataset (split 70/20/10), ekspor bobot best.pt/best.onnx, dan uji Before vs After otomatis.
