💻 Jawaban Rubrik: “Ada GUI, Dijelaskan Pakai Bahasa Pemrograman Apa?”

Full-Stack AI CV

Aplikasi GUI NusantaraVision YOLOv11 dibangun dengan arsitektur web modern berbasis browser dan backend AI Computer Vision:

Frontend Web GUI

HTML5 + CSS3 + JavaScript (ES6+)

  • HTML5 Canvas 2D & Video API: Rendering citra/video real-time, manipulasi piksel langsung (ImageData) untuk HE, CLAHE, Contrast Stretching, Gamma LUT, serta bounding box & ROI interaktif.
  • JavaScript ES6+: State management deteksi, simulasi ByteTrack ID & motion trail, drag/resize Object Region #1, generator ekspor CSV/Excel, dan klien REST API Supabase.
  • CSS3: Desain gelap modern responsif (CSS Grid & Flexbox) tanpa dependensi eksternal agar berjalan lancar baik via http://localhost:8000 maupun file://.
Backend & Deep Learning

Python 3 + FastAPI + OpenCV + YOLOv11

  • Python 3.10+ & Ultralytics YOLOv11: Model yolo11n.pt terlatih pada 600 citra kuliner (12 kelas) untuk deteksi, Object Counting, dan ByteTrack Multi-Object Tracking.
  • OpenCV (cv2) & NumPy: Implementasi server-side YCrCb HE, LAB CLAHE, Percentile Contrast Stretching, dan cv2.pointPolygonTest untuk Region Counter #1.
  • FastAPI + OpenPyXL: REST API endpoint (/api/detect/image, /api/detect/video, /api/export/excel) & Node.js v24 (server.js) fallback zero-dependency.
Database & Training

PostgreSQL (Supabase) + Google Colab (.ipynb)

  • SQL / PostgreSQL (Supabase): Skema relasional (culinary_classes, detection_sessions, enhancement_comparisons) lengkap dengan Row Level Security (RLS) dan REST API.
  • Google Colab Jupyter Notebook (.ipynb): Pipeline training GPU T4 (70% train / 20% valid / 10% test), ekspor model best.pt & best.onnx, serta laporan Excel otomatis.
